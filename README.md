# emmabranch.github.io

The home page of Emma Branch's portfolio: flash sheets of tattoo motifs that link to each project, and a gallery of all the projects.

**Live site:** [emmabranch.github.io](https://emmabranch.github.io/) | **More projects:** [github.com/emmabranch](https://github.com/emmabranch)

Built with Quarto and the shared portfolio brand kit. To rebuild: `quarto render`. The site is written to `docs/`.
